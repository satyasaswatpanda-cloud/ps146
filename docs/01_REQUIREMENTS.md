# Prototype Requirements

## Required by the problem statement
- ingest bulk Bitcoin transaction/network metadata
- support CSV, JSON, and XML
- correlate network-layer information with blockchain-layer information
- build an entity/transaction graph
- include a working AI/ML model, not only rules
- generate explainable prioritized alerts with confidence
- present findings in a dashboard or link-analysis visualization
- support an offline Linux solution

## Prototype acceptance criteria
- application starts locally
- sample dataset can be analyzed in one click
- CSV upload works
- JSON/XML parser paths exist
- ML model executes
- graph summary is produced
- alerts provide reasons and confidence
- tests pass
